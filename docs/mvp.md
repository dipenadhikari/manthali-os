# MVP Specification

## Core workflow

**Find a public service → understand it → see what to prepare → build a checklist → verify against the official source.**

## MVP features

### 1. Service directory

Users can:

- search services
- browse categories
- see responsible departments
- open service detail pages

### 2. Service detail page

Each service can contain:

- service name
- plain-language description
- eligibility
- required documents
- preparation steps
- responsible department
- official source
- verification status
- verification date

### 3. Personal checklist

A user can:

- save a service
- create a preparation checklist
- mark requirements complete
- track preparation progress

### 4. Admin workflow

Authorized admins can:

- create services
- edit services
- manage requirements
- attach official sources
- verify information
- publish or unpublish services

### 5. AI assistance

AI may transform curated service information into easier language.

AI output must clearly remain informational. Official sources remain authoritative.

### 6. Analytics

Track product events needed to understand usage without collecting unnecessary personal data.

## Out of scope

- government API integration
- application submission
- payments
- document uploads containing sensitive identity information
- financial transactions
- automated government decisions
